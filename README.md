# qwt_c

Simulation code and recorded results for the MS Physics thesis
*Quantum Walks as a Tool for Quantum Machine Learning Algorithms*
(School of Natural Sciences, NUST, Islamabad).

Each `implementation_*` directory has its own README with the run order.

## Requirements

Python 3.11+ with numpy, scipy, networkx, scikit-learn, matplotlib,
qiskit (>= 2) and qiskit-aer.
